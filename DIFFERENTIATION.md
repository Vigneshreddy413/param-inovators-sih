# THERMOSENTRY COMPETITIVE DIFFERENTIATION

**NASA FIRMS (Baseline)**
→ satellite-derived thermal anomaly observation

*NASA FIRMS effectively provides the raw telemetry: "We observed heat at these coordinates."*

---

**THERMOSENTRY (Intelligence Layer)**
→ observation
→ context
→ temporal behavior
→ anomaly analysis
→ evidence
→ risk prioritization
→ analyst investigation.

*THERMOSENTRY provides the 'so what': "We observed heat, it is completely abnormal for this region's industrial footprint, it has escalated by X% since yesterday, we have HIGH confidence in the satellite observation, and an analyst should review it immediately."*
